# Rogelio Gutierrez — Portfolio & CV Website

Personal portfolio and resume website of Rogelio Gutierrez, Full Stack Developer Trainee & Computer Systems Engineering Student at Universidad Autónoma de Aguascalientes (UAA).

🌐 **Live Website**: [https://roger934.github.io/portfolio/](https://roger934.github.io/portfolio/)

---

## 🛠️ Technologies Used

- **Frontend**: HTML5 (Semantic & Accessible), CSS3 (Custom properties, CSS Grid, Flexbox, Mobile-First), Vanilla JavaScript (ES6+)
- **Design**: Minimalist, formal, high contrast, responsive, with print support (`@media print`)
- **Hosting**: GitHub Pages

## 📂 Project Structure

```

├── script.js        # Navigation, active section observer & clipboard copy
├── favicon.svg      # Minimalist SVG favicon
```
